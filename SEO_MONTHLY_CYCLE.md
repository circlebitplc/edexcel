# Monthly SEO cycle — edexcel.college

**Cadence:** First working week of each month  
**Loop:** Measure → Identify → Improve → Publish (sparingly) → Monitor → Repeat

## Checklist

1. **Search Console** — clicks, impressions, CTR, position; queries & pages; countries; devices  
2. **Analytics** — organic sessions, landing pages, enquire events/goals  
3. **Ranking opportunities** — positions 4–20, high impressions  
4. **Declining pages** — −impressions or −CTR MoM; diagnose intent/cannibalization  
5. **Improve existing content** — before writing anything new  
6. **New content** — only high-value gaps with clear service link  
7. **Technical** — coverage, redirects, robots, sitemap freshness  
8. **Core Web Vitals** — re-test top landings if regressions suspected  
9. **Broken links** — sample crawl of hub + country + guides  
10. **Conversions** — enquiry count & quality; fix funnel friction  

## Guardrails

No keyword stuffing, fake locations/reviews, doorway pages, spam backlinks, or Pearson ownership claims.

## Output

Append a short monthly note to `SEO_CHANGELOG.md` and update priorities in the execution dashboard canvas / `SEO_EXECUTION_DASHBOARD.md`.

# Keyword → URL map (anti-cannibalization)

**Primary rule:** one commercial/informational intent → one primary URL; others support via links.

| Keyword / topic | Primary page | Supporting pages |
| --- | --- | --- |
| Pearson Edexcel exam services (brand+service) | `/pearson-exams` | `/about`, `/resources` |
| Edexcel classes Kandy / campus tuition | `/edexcel-classes` | `/locations/kandy`, `/pearson-exams/sri-lanka` |
| Kandy location / NAP | `/locations/kandy` | `/contact`, `/about` |
| IGCSE / “Edexcel O Level” | `/edexcel-o-level` | `/glossary#igcse`, `/exam-preparation`, `/guides/igcse-vs-edexcel-o-level` |
| A Level / IAL | `/edexcel-a-level` | `/glossary#ial`, `/exam-preparation` |
| Exam preparation / past papers | `/exam-preparation` | guides, FAQ |
| How Pearson exams work | `/guides/how-pearson-edexcel-exams-work` | hub, glossary |
| How to register / entry | `/guides/how-to-register-for-pearson-exams` | `/guides/private-candidates`, FAQ#registration |
| Private candidate | `/guides/private-candidates` | register guide, FAQ |
| Exam day / what to bring | `/guides/what-to-bring-to-a-pearson-exam` | FAQ#exam-day |
| Results / certificates | `/guides/results-and-certificates` | FAQ#results, glossary |
| FAQ / PAA catch-all | `/faq` | category anchors |
| Terminology | `/glossary` | linked guides |
| Resources hub / topical authority | `/resources` | all guides |
| Sri Lanka | `/pearson-exams/sri-lanka` | `/locations/kandy` |
| Italy / Qatar / Oman / UAE / Maldives / UK / India / Gulf | `/pearson-exams/{slug}` | `/resources`, enquire |
| Brand “Edexcel College” | `/about` | home, contact |
| Contact / enquire (transactional) | `/contact`, `/admissions/enquire.php` | CTAs sitewide |

**Intent split (important)**

- `/edexcel-classes` = enrol in **campus/online classes**  
- `/pearson-exams/sri-lanka` = **country overview** (tuition + local exam realities)  
- `/locations/kandy` = **city/campus** NAP and process  

Do not create additional “Edexcel tuition in {random city}” pages.

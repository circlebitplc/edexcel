What is networking?

A computer network comprises two or more computers that are connected—either by cables (wired) or wifi (wireless)—with the purpose of transmitting, exchanging, or sharing data and resources.

Computer Resources

1. Devices

Hardware resources such as input/output devices (keyboard, mouse, printer) and networking devices (routers, switches).

2. Memory (Can not be shared)

RAM (Random Access Memory),Cache Memory and Register Memory are considered memory resources.

3. Process

CPU (Central Processing Unit) and related resources (VGA) for executing computer programs.

4. File

Storage resources for storing and managing digital files and data.

5. Security

Security resources include hardware and software components such as firewalls, antivirus software, encryption tools, and access control mechanisms.

6. Network

Networking resources encompass hardware (routers, switches, NICs) and software (protocols, services) components used for communication between devices in a network.

Computer network types

1) LAN (local area network)

2) WLAN (wireless local area network)

3) WAN (wide area network)

4) MAN (metropolitan area network)

5) PAN (personal area network)

6) SAN (storage area network)

8) CAN (campus area network)

9) VPN (virtual private network)

1) LAN (local area network)

  • A LAN connects computers over a relatively short distance,
  • Allowing them to share data, files, and resources.
  • A LAN may connect all the computers in an office building, school, or hospital. Typically,
  • LANs are privately owned and managed.

    • 2)WLAN (wireless local area network)

    A WLAN is just like a LAN but connections between devices on the network are made wirelessly.

    3) WAN (wide area network)

    As the name implies, a WAN connects computers over a wide area, such as from region to region or even continent to continent. The internet is the largest WAN, connecting billions of computers worldwide. You will typically see collective or distributed ownership models for WAN management.

    4) MAN (metropolitan area network)

    MANs are typically larger than LANs but smaller than WANs. Cities and government entities typically own and manage MANs.

    5) PAN (personal area network)

    A PAN serves one person. For example, if you have an iPhone and a Mac, it’s likely you’ve set up a PAN that shares and syncs content—text messages, emails, photos, and more—across both devices.

    6) SAN (storage area network)

    A SAN is a specialized network that provides access to block-level storage—shared network or cloud storage. To the user, it looks, and works like a storage drive that’s physically attached to a computer.

    8) CAN (campus area network)

    A CAN is also known as a corporate area network. A CAN is larger than a LAN but smaller than a WAN. CANs serve sites such as colleges, universities, and business campuses.

    9) VPN (virtual private network)

    A VPN is a secure, point-to-point connection between two network end points (see ‘nodes’ below). A VPN establishes an encrypted channel that keeps a user’s identity and access credentials, as well as any data transferred, inaccessible to hackers.

    1) LAN (local area network)

    1.1 Advantages of LAN

    • Software and data files can be shared by many users.
    • Users can work together on a single shared document.
    • Users can communicate using instant messaging.
    • Users can stream media.
    • Users can access the network from any computer or other device that can be attached to the network.
    • It is usually cheaper to buy one copy of a software application and pay the license fee for several computers, than to buy individual licenses for each computer.
    • Users can share hardware devices.
    • Users can share an Internet connection.
    • User’s access rights can be controlled centrally.
    • Computers attached to the network can be maintained either centrally or from any network station.

    1.2 Disadvantages of LAN

    • Set-up of server and network cabling costs high.
    • Data can get corrupt easily.
    • There is a risk from viruses as they can spread easily between the computers.

    1.3 Types of LAN

    1. Client / Server
    2. peer-to-peer network

    1.3.1 Client / Server

    A Client/Server LAN (Local Area Network) architecture is a network setup in which client devices communicate with server devices over the LAN. In this architecture, devices on the network are divided into two categories

  • Client Devices
  • Server Devices

    • 1 Client Devices

  • These are typically end-user devices such as desktop computers, laptops, tablets, smartphones, and other devices that request services or resources from the server.
  • Client devices rely on the server for various services, such as file storage, database access, printing, email, web browsing, and more.
  • Examples of client devices include workstations used by employees in an office environment

    • 2 Server Devices

  • These are computers or specialized hardware devices that provide services or resources to client devices on the network.
  • Servers are dedicated to specific tasks or services and often have more powerful hardware configurations compared to client devices.
  • Examples of server devices include file servers, database servers, web servers, email servers, print servers, and application servers.
